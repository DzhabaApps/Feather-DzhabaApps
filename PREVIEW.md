# Физер: отдельная тестовая версия

Основа: стабильный релиз Feather **2.9.0** от 5 июля 2026 года.
Ветка: `codex/fizer-russian-preview`. Основная ветка и выдача сертификатов ботом не переключаются.

## Изменения

- Русский интерфейс выбран по умолчанию, включая настройки, действия в каталоге, библиотеку и сообщения приложения. Названия приложений, данные сертификатов, текст лицензии и описания из внешних репозиториев сохраняются в исходном виде.
- Основные настройки: сертификат, установка, хранилище, помощь, дополнительные параметры и сведения о приложении.
- SSL обновляется из исходного сервиса backloop.dev. Кнопка доступна в обычных настройках установки, показывает процесс и результат. Она не продлевает сертификат подписи Apple.
- Сложные настройки подписи, VPN/сопряжения, сжатия, оформления и сброса сохранены в «Дополнительно».
- Убраны баннер пожертвований, предложения поставить звезду, отправка отзыва и рекламный блок спонсоров. Авторство и GPL-3.0 сохранены.
- В репозитории: «Скачать» → загрузка/распаковка → «Установить» → подпись → установка iOS. В библиотеку переходить не требуется.
- Связь файла с карточкой сохраняется в существующем поле Core Data `source`. Учитываются URL загрузки и версия каталога; новая версия по старому URL загружается отдельно.
- При ошибке подписи исходник остаётся. После успешной подписи очистка исходника следует сохранённой настройке; подписанная копия остаётся для повторной установки.
- Установка привязана к конкретному результату подписи, а не к последнему файлу в библиотеке.

Ограничение срока доступа и продолжение прерванной загрузки в этот этап не входят.

## Изоляция

Bundle ID: `ru.dzhabaapps.fizer.preview`.
Название на домашнем экране: **Физер-тест**.
Схема ссылок: `fizer-preview://`; тестовая сборка не регистрирует `feather://`.
Клиентские сертификаты и пароли в базовую тестовую сборку не включаются.
Для установки на iPhone IPA нужно отдельно подписать сертификатом и профилем этого устройства.
Совместимость профиля с отдельным Bundle ID проверяется перед подписью.

На Linux VPS хранятся исходники и готовый IPA. Нативная сборка выполняется Xcode 26.3 в существующем GitHub Actions Release workflow, запущенном на тестовой ветке. Результат сохраняется как draft release; его публикация не требуется для проверки владельцем.

## Проверки перед передачей

`make` проверяет русские переводы и аргументы форматирования, запускает пять Swift-проверок идентичности файлов и одиннадцать проверок реального координатора установки с Core Data в памяти, собирает iOS Release и проверяет содержимое IPA: Bundle ID, название, URL-схему, русский каталог, GPL, SSL-файлы, отсутствие клиентских ключей и целостность ZIP.

На настоящем iPhone проверить:

1. Запуск рядом с рабочим Feather и русский интерфейс.
2. Настройки: отсутствие баннеров, доступность дополнительных параметров.
3. Обновление SSL: успех при доступной сети и понятная ошибка без сети.
4. Импорт сертификата устройства и скачивание небольшого IPA из нашего репозитория.
5. Появление «Установить» без перехода в библиотеку; подпись и системное подтверждение iOS.
6. Повторное открытие приложения: скачанный/подписанный файл по-прежнему доступен из каталога.
7. Ошибка подписи и отказ от установки: возможность повторить попытку.
8. Новая версия в каталоге по прежнему URL: предлагается новая загрузка.

Успешная компиляция и проверки артефакта не подтверждают установку на физическое устройство.
